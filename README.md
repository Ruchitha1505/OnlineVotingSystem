# 🗳️ Online Voting System

An Online Voting System developed in C programming to provide a secure, efficient, and user-friendly platform for conducting elections. The system allows voter registration, candidate management, vote casting, vote counting, and result declaration while ensuring that each voter can cast only one vote.

---

## 📖 Project Overview

The Online Voting System is a console-based application developed using the C programming language. It automates the election process by maintaining voter and candidate records, securely recording votes, and displaying election results. The project demonstrates core programming concepts such as structures, functions, arrays, file handling, modular programming, and data management.

---

## 🎯 Objectives

- Digitize the election process.
- Register voters and candidates.
- Allow secure vote casting.
- Prevent duplicate voting.
- Count votes automatically.
- Display election results accurately.
- Reduce manual errors.
